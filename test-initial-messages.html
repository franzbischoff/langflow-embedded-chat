🧪 Testing Initial Messages Feature

Test 1: Empty Chat (No History)

This chat widget starts with no messages. This is the default behavior.

Test 2: Chat with Pre-loaded History

This chat widget is pre-populated with conversation history. This simulates loading messages from a database.

Test 3: Laravel/jQuery Simulation

This simulates a Laravel backend integration where chat history is fetched via AJAX.

Test 4: Mixed Messages (User + Bot + Errors)

This demonstrates all message types: user messages, bot messages, and error messages.

📝 How to Use:

  1. Click the buttons in each test section
  2. Refresh the page to see the messages loaded
  3. Or set the initial_messages attribute before page load

💡 Message Format:

{
  "message": "The message text",
  "isSend": true,  // true for user, false for bot
  "error": false   // optional, true for error messages
}
