🧪 Testing Initial Messages Feature

Test 1: Empty Chat (No History)

This chat widget starts with no messages. This is the default behavior.

Test 2: Chat with Pre-loaded History

This chat widget is pre-populated with conversation history. This simulates loading messages from a database.
Note: The widget is dynamically created with history already set.

Test 3: Laravel/jQuery Simulation

This simulates a Laravel backend integration where chat history is fetched via AJAX.
Note: The widget is created after data is fetched.

Test 4: Mixed Messages (User + Bot + Errors)

This demonstrates all message types: user messages, bot messages, and error messages.
Note: The widget is dynamically created with all message types.

📝 How to Use:

  1. Click the buttons in each test section to create widgets with history
  2. The widgets are created dynamically with messages already loaded
  3. In production, fetch data from your backend before creating the widget

⚠️ Important Notes:

  • The initial_messages attribute must be set before the widget is rendered
  • Setting it after initialization will not update the messages
  • For dynamic loading, create the widget element programmatically after fetching data

💡 Message Format:

{
  "message": "The message text",
  "isSend": true,  // true for user, false for bot
  "error": false   // optional, true for error messages
}
