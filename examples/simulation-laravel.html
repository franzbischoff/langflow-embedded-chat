🔧 Como funciona (Simulação do Laravel):

1️⃣ Carregar Histórico (Laravel Controller):

// Simulação do que acontece no backend Laravel function getChatHistory(userId) { // Em Laravel: DB::table('chat_messages')->where('user_id', userId)->get() const key = 'chat_history_' + userId; const history = localStorage.getItem(key); return history ? JSON.parse(history) : []; }

2️⃣ Injetar no Widget (Frontend jQuery):

// No seu HTML Laravel + jQuery $.get('/api/chat/history/' + userId, function(history) { const chat = document.createElement('langflow-chat'); chat.setAttribute('host_url', '...'); chat.setAttribute('flow_id', '...'); // 🌟 Injetar histórico 🌟 if (history && history.length > 0) { chat.setAttribute('initial_messages', JSON.stringify(history)); } document.body.appendChild(chat); });

3️⃣ Salvar Nova Mensagem (Laravel API):

// Quando o utilizador envia uma mensagem function saveMessage(userId, text, isUser) { // Em Laravel: DB::table('chat_messages')->insert([...]) const history = getChatHistory(userId); history.push({ message: text, isSend: isUser, timestamp: new Date().toISOString() }); localStorage.setItem('chat_history_' + userId, JSON.stringify(history)); }
