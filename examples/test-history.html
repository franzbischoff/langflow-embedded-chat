ℹ️ Instruções:

  1. Configure as credenciais do Langflow acima (Host URL, Flow ID, API Key)
  2. Edite o JSON do histórico ou use um dos exemplos
  3. Clique em "Iniciar Chat com Histórico"
  4. O chat deve abrir automaticamente com as mensagens do histórico
  5. Abra o Console (F12) para ver os logs

🔍 Verificar:

  • As mensagens antigas devem aparecer no chat
  • Mensagens do utilizador (isSend: true) à direita
  • Mensagens do bot (isSend: false) à esquerda
  • Console deve mostrar: "Histórico injetado: X mensagens"
